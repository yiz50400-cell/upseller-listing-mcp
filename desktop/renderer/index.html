设置

登录沿用现有本机会话方案（upseller_login / 本机 mcp/.env）。成功只显示长度，不回显 Cookie 或 DeviceId。打开本软件即可使用，不需要安装 Cursor 或 Codex。

固定每批 8 个商品。默认只预览；保存草稿不会发布；发布必须在弹窗中再次确认。

确认发布？

发布不是默认行为。只有你再次确认后，才会把 confirmPublish=true 交给现有上架能力。预览和保存草稿都不会发布。
